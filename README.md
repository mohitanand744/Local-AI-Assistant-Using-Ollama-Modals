# 🐉 Coding Beast

Coding Beast is a safe, completely local, privacy-friendly AI developer assistant for Windows 11. It idles quietly in the background, wakes up to your voice, and securely performs developer tasks (like checking Git, managing tasks, or launching code projects) without sending any data to the cloud.

---

## 🚀 Features

- **Local-First & Private:** All audio and data are processed locally. No OpenAI, Google, or Cloud APIs.
- **Low-Resource Idle:** Uses an ultra-lightweight Vosk engine to detect the "Hello My Coding Beast" wake word without keeping your GPU active.
- **Dynamic Voice Activity Detection:** Smart audio recording stops automatically when you finish speaking.
- **Smart Execution:** Uses Ollama (Qwen 2.5 Coder 7B) to determine intents safely.
- **Safe PC Controls:** Operates via strict allowlists to prevent dangerous arbitrary commands.

## 🛠️ Installation & Setup

### 1. Python Environment
Ensure you have Python 3.13 installed.
```bat
git clone <your-repo> C:\AI-Assistant
cd C:\AI-Assistant
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
*(Make sure `requirements.txt` contains `sounddevice`, `soundfile`, `faster-whisper`, `vosk`, `ollama`, `piper-tts`, and `numpy`)*

### 2. Ollama Setup
1. Install [Ollama](https://ollama.com/) for Windows.
2. Open a terminal and pull the brain model:
```bat
ollama run qwen2.5-coder:7b
```

### 3. Whisper Setup
Whisper is installed via `faster-whisper` in the requirements. No external installation is needed, but it heavily benefits from NVIDIA CUDA Toolkit installed on your system. The script will automatically load the `"small"` model on first run.

### 4. Piper Setup
Ensure the Piper voice model (`en_US-lessac-medium.onnx`) is located in `models/`.

### 5. Vosk Setup
The lightweight wake-word engine requires the small English model.
Download `vosk-model-small-en-us-0.15.zip` from alphacephei and extract it so that the folder path is `models/vosk-model`.

## 💻 Running the Assistant

You can launch Coding Beast in three ways:

1. **Double Click:** Double-click `start_coding_beast.bat` to launch it instantly.
2. **Windows Startup:** Press `Win + R`, type `shell:startup`, and place a shortcut to `start_coding_beast.bat` in that folder to run it every time you boot your PC.
3. **Manual CLI:**
```bat
.venv\Scripts\activate
python coding_beast.py
```

### Interaction Flow
1. Coding Beast will print **"💤 Coding Beast is in low-resource idle mode."**
2. Say **"Hello My Coding Beast"**.
3. It will reply **"Yes?"**.
4. Give it a command (e.g., "Check Git status").
5. When finished with your session, say **"Exit"** to return it to sleep mode.

## ⚙️ Configuration & Adding Features

All settings are stored in `config.py`. 

### Adding Projects
To let Coding Beast open your specific coding projects or check their Git status, simply add the path to the `PROJECTS` dictionary in `config.py`:
```python
PROJECTS = {
    "ai assistant": BASE_DIR,
    "nextchapter": r"C:\path\to\your\NextChapter",
}
```

### Adding New Tools
1. **Write the Function**: Add your python function to `dev_tools.py` or `tools.py`.
2. **Update the System Prompt**: In `brain.py`, update `SYSTEM_PROMPT` to teach the AI the JSON structure it must output to trigger your tool.
3. **Update the Router**: In `brain.py`, map the JSON `action` string to your new Python function inside `ask_coding_beast()`.

### Safety Model
Coding Beast DOES NOT execute arbitrary terminal commands generated by the LLM. It maps intents to strictly defined, allowlisted Python functions (e.g., it can only open applications defined in `config.py`). Always maintain this architecture when extending the bot!

## ⚠️ Troubleshooting

- **Audio not recording/crashing?** Make sure your default Windows microphone is correctly set in the Sound Control Panel.
- **Whisper is slow?** Ensure you have CUDA configured and your environment can access the `.venv\Lib\site-packages\nvidia` DLLs.
- **"Vosk model not found" error?** Make sure you extracted the vosk model exactly to `C:\AI-Assistant\models\vosk-model`.
